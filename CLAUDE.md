# Overview

Personal website for Dominic Harrington. Plain static HTML/CSS with no build step or npm. Served files live in `site/` and are deployed to GitHub Pages by `.github/workflows/deploy.yml`.

The home page is the full-screen looping showreel (`site/media/showreel.*`) with three persistent buttons: Thesis (`thesis.pdf`), CV (`cv.pdf`) and Skiing game (`skicross.html`). The visual style (dark ground, mono type, teal/orange accents) matches the showreel's HUD.
